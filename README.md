# setori-board

ジャグリングの演技構成（セットリスト）を組み立てる、自分専用の Windows アプリ。
曲を「ブロック」に区切り、各ブロックに技カードを並べ、ドラッグで並べ替えながら構成を練る。

## 使い方（おもな操作）

| 操作 | やり方 |
| --- | --- |
| 再生／一時停止 | Space または ▶ |
| ブロックの頭から再生 | ブロックの見出し、またはタイムライン上段の区間をクリック |
| 好きな位置から再生 | タイムライン下段の波形をクリック |
| ブロック名の変更 | ブロックの見出しをダブルクリック |
| 曲を区切る | ［区切りモード］→ 曲を流しながら M。←→ で ±0.1 秒、Shift+←→ で ±1 秒、↑↓ で区切りを選択、Delete で削除、Esc で完了 |
| カードを置く | 下の技ストックからブロックへドラッグ |
| カードの並べ替え・移動 | カードをドラッグ（Esc で取り消し） |
| カードの編集 | カードをクリック（個数・メモ・技の変更、削除） |
| 元に戻す／やり直し | Ctrl+Z ／ Ctrl+Y（Ctrl+Shift+Z） |
| 技の編集・削除 | 技ストックのチップをダブルクリック／右クリック |

データは `%APPDATA%\setori-board` に JSON で保存される（変更のたびに自動保存）。
音楽ファイルはプロジェクト作成時にこのフォルダへコピーされる。

## 開発

PowerShell で `npm` がエラーになる場合は `npm.cmd` に読み替える。

```bash
npm install
```

```bash
npm start
```

```bash
npm test
```

ファイル構成：

| ファイル | 役割 |
| --- | --- |
| `main.js` | メインプロセス。ウィンドウ、ファイル保存、自動アップデート |
| `preload.js` | 画面に公開する API |
| `src/app.js` | 画面全体の状態と画面切替、キー操作 |
| `src/list.js` | プロジェクト一覧と新規作成 |
| `src/editor.js` | 編集画面（再生、タイムライン、ブロックレーン、区切りモード、ドラッグ、元に戻す） |
| `src/popover.js` | カード編集ポップオーバー |
| `src/stock.js` | 技ストック |
| `src/blocks.js` | 区切りの計算（分ける・動かす・結合する） |
| `src/peaks.js` | 波形ピークの計算 |
| `src/update.js` | アップデートのボタン |
| `src/style.css` | デザイントークンと見た目 |

## exe を作る

```bash
npm run dist
```

`dist\setori-board-Setup-<版>.exe` ができる。ダブルクリックでインストールされる（ユーザー単位、管理者権限は不要）。
コード署名をしていないため、初回は Windows SmartScreen の警告が出る。「詳細情報」→「実行」で進める。

## 新しい版を配布する（自動アップデート）

アプリは起動するたびに GitHub Releases（`jagjag-yt/setori-board`）を確認し、新しい版があれば画面右上に［アップデート］ボタンを出す。
押すとダウンロードし、［再起動して更新］で入れ替わる。

新しい版の出し方：

1. `package.json` の `"version"` を上げる（例 `0.1.0` → `0.2.0`）
2. 変更をコミットして push する
3. 次のコマンドを実行する（GitHub CLI `gh` でログイン済みであること）

```bash
npm.cmd run release
```

インストーラをビルドし、`gh` で GitHub Releases に公開する（`scripts/release.mjs`）。インストール済みのアプリは次の起動時に気づく。
